# Seguridad

No publiques credenciales, tokens ni datos personales en issues o pull requests.

Si encuentras una vulnerabilidad, informa a las personas responsables del repositorio de forma privada usando el canal de contacto que hayan configurado en GitHub. Incluye pasos para reproducir el problema y su impacto. Evita divulgar los detalles públicamente hasta que exista una solución.

Este proyecto es una demostración. Antes de usarlo en producción, revisa la autenticación y autorización del panel administrativo, configura HTTPS y aplica controles operativos adecuados.
