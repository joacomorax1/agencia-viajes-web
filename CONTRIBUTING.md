# Contribuir

Gracias por ayudar a mejorar Horizonte Travel.

## Proponer cambios

1. Abre un issue para describir el problema o la mejora y su alcance.
2. Crea una rama con un nombre claro, por ejemplo `fix/busqueda-fecha` o `docs/instalacion`.
3. Mantén cada cambio enfocado y sigue la organización existente: PHP en `includes/` y `views/`, estilos en `assets/css/` y JavaScript en `assets/js/`.
4. Antes de abrir un pull request, revisa los cambios y confirma que GitHub Actions informa correctamente la sintaxis PHP.
5. Describe qué cambiaste y cómo se puede revisar desde la interfaz.

No incluyas contraseñas, claves, datos personales ni archivos locales de configuración.
